Chrome on Windows, macOS or Linux
  1. Open OnTrack in a regular Chrome window.
  2. Select the install icon in the address bar, or open the browser menu and choose Cast, save and share → Install page as app.
  3. Confirm installation, then open OnTrack from your app launcher.
Microsoft Edge
  1. Open OnTrack in a regular Edge window.
  2. Select the install icon in the address bar, or choose Settings and more → More tools → Apps → Install this site as an app.
  3. Confirm installation. You can find OnTrack in Edge’s Apps page.

If Edge on Linux does not offer installation, use Chrome or continue in your browser.

Safari on macOS
  1. Open OnTrack in Safari on macOS Sonoma 14 or later.
  2. Choose File → Add to Dock from the menu bar.
  3. Choose Add, then open OnTrack from the Dock.

You may need to sign in again in the new app window.

Firefox and other desktop browsers

On Windows, Firefox 143 or later offers a web apps button in the address bar to add a site to your taskbar. Firefox installed from the Microsoft Store needs version 150 or later.

If your browser has no install option, including Firefox on macOS or Linux, keep using OnTrack in this tab or open it in Chrome. On a supported Mac, you can also use Safari’s Add to Dock.

iPhone, iPad or Android

iPhone and iPad: Open OnTrack in Safari, tap Share, then Add to Home Screen and confirm.

Android: Open OnTrack in Chrome, open its menu, then choose Install app or Add to Home screen and confirm.

Missing an install option? Check whether OnTrack is already in your app launcher. Try a regular browsing window; private browsing and your organisation’s browser settings can limit installation.
