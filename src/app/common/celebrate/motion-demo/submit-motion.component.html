Handing in a portfolio

The end of a whole unit, which a student reaches once per unit per trimester. It is the rarest thing here, so it is the slowest: the mark draws at 2.6 times the usual pace, the words arrive after it lands, and the facts settle one at a time. It has no timer, because this is the one moment worth staying on.

What is the same in all six

The circle turns green the moment the bytes land, before the confirmation is worked out, so the wait for the server is not dead time. The mark's space is reserved from the start, so nothing below it moves when the circle grows. And the bar never disappears: it folds to nothing, because something vanishing is the thing that reads as a new screen.
